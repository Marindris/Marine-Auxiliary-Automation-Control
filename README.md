# Marine Auxiliary Systems Automation & Control – PLC/HMI Simulation

## Project Goal
Design and simulate a PLC/HMI control system for a marine auxiliary service-water system.

## Initial System
The system will contain:
- Service water tank T-101
- Level transmitter LT-101
- Duty pump P-101A
- Standby pump P-101B
- Motorised valve XV-101
- PLC control
- HMI monitoring and control

## Planned Features
- Auto and Manual operation
- Duty/standby pump control
- Pump permissives and interlocks
- High and low tank-level alarms
- Pump failure detection
- Automatic standby-pump changeover
- HMI alarms and status indication
- FAT simulation and testing
